# Python Quest ปวช.

เกมฝึกเขียนโปรแกรมภาษา Python สำหรับนักเรียนระดับ ปวช. ผู้เล่นต้องเขียนโค้ดควบคุมหุ่นยนต์ให้เก็บชิปและเดินไปถึงธง

## เนื้อหา

- ด่าน 1: คำสั่งแบบลำดับด้วย `move()`
- ด่าน 2: การตัดสินใจด้วย `if on_blue():`
- ด่าน 3: การตัดสินใจด้วย `if wall_ahead():`

คำสั่งที่ใช้ในเกม ได้แก่ `move()`, `turn_left()` และ `turn_right()`

## วิธีเปิดเกม

เปิด `index.html` ด้วยเว็บเบราว์เซอร์ หรือเปิด local server จากโฟลเดอร์นี้:

```bash
python3 -m http.server 4173
```

จากนั้นเปิด <http://localhost:4173>

เกมทำงานในเว็บเบราว์เซอร์และไม่ต้องติดตั้งไลบรารีเพิ่มเติม
